# Design notes

These are raglit's former plan documents, moved here on 2026-10-24. They record
why the code is the way it is: the measurements, the alternatives considered,
and the decisions made.

They are history, not a to-do list. Status marks (◻ ◐ ❓ ⏸) and "next" lines in
them are stale. Open work is tracked as aw4 issues in project raglit, and each
open item from these files was filed there on 2026-10-24.

Code comments cite these files by path. When a note no longer matches the code,
the code is correct.
