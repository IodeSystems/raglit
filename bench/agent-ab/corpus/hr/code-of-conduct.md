# Code of Conduct

We expect respect in every interaction: meetings, chat, code review and
company events.

## Not acceptable

Harassment, demeaning jokes, unwelcome comments about someone's appearance or
identity, and retaliation against anyone who raises a concern.

## Raising a concern

- Talk to your manager or to People Operations, if you are comfortable doing
  so.
- Or use SpeakSafe, the independent line run outside the company
  (speaksafe.example or 555-0142). SpeakSafe never passes on your name
  unless you ask it to.

Every concern is looked into. Retaliation is itself a breach of this code.
