# Access to code and systems

All access goes through Gatehouse, the access request tool. Nobody grants
access by hand.

## Employees

Your manager's onboarding request covers the standard set for your team.
Anything else: request it in Gatehouse; the system owner approves.

## Contractors and freelancers

The Thornbury manager who hired them is their sponsor. The sponsor files the
request in Gatehouse with the contract end date. Contractor access expires
after 90 days or at the contract end date, whichever comes first, and must be
renewed by the sponsor. Contractors get repository access only to the
repositories named in the request, never organization-wide.
