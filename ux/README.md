# Focus-group walks

Walks for the raglit web UI. Personas walk each step in a browser, read-only,
and score it against its promise. A walk names a scenario in `scenarios/`: who
the persona is and what they came to do.

The walks assume a small handbook corpus for a fictional company, Larkspur
Tools: the four `cmd/raglit/demodata` documents plus an incident report, meeting
notes, an onboarding guide and a hosting agreement summary. Use invented
documents only: this repository is public.
